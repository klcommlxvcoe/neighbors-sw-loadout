## Overview

Neighbors: Suburban Warfare Loadout is a companion web app for the multiplayer suburban sabotage game Neighbors: Suburban Warfare, providing a drag-and-drop loadout builder for gadgets and sabotage tools, damage output calculations, recommended counter-pick suggestions against common enemy loadouts, and a community-curated strategy guide for each map.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Neighbors Suburban Warfare Loadout** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Loadout Builder** | Drag-and-drop tool builder showing total slots and synergy ratings |
| **Damage Calculator** | Calculate sabotage tool effectiveness and timing in combo chains |
| **Counter Suggestions** | Recommended tools that counter the most common opponent loadouts |
| **Map Strategies** | Community guide with recommended setups for each map objective |
